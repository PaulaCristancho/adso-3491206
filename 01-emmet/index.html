01-EMMET

Plugin para codificación más rápida en HTML y CSS.

01-Child >
Crea elementos hijos (anidación).

Ejemplo:

ul>li>a ↔️

Resultado:

<ul> <li> <a href=""></a> </li> </ul>

02-sibling: +
Crea elementos hermanos.

Ejemplo:

section+menu+div ↔️

Resultado:

<section></section> <menu></menu> <div></div>

03-Multiplication: *
Repite elementos varias veces.

Ejemplo:

ul>li*5 ↔️

Resultado:

<ul> <li></li> <li></li> <li></li> <li></li> <li></li> </ul>

04-Class: .
Crea un atributo de clase.small>

Ejemplo:

menu.main .container ↔️

Resultado:

<menu class="main"></menu> <div class="main"></div>

08-relative-units

Las unidades relativas en CSS son aquellas que se basan en otras medidas para calcular su valor.

  • Pixel (px)
  • M (em)
  • X (ex)
  • Root M (rem)
  • Viewport Units Horizontal (wh)
  • Viewport Units Vertical (vh)
  • large Viewport (lvw, lvh)
  • Small Viewport (svw, svh)
  • Dynamic Viewport (dvw, dvh)

Ejemplo:

  • px: 15px
  • em: 1.5em
  • rem: 2rem
  • ex: 2.4ex

17-visualization

define cómo se muestran los elementos en la página mediante propiedades como display que controlan el diseño y el flujo de los cuadros de contenido

  • Display: block|inline|none|flex|grid
  • Visibility: visible|hidden
  • Overflow: visible|hidden|scroll|auto
  • Z-Index: 1...n
